# uhohbrands.com

Static site for Uh Oh, a zinc cold remedy. Plain HTML and CSS, no build step.

- `index.html` is the whole site.
- `style.css` holds the styles. Brand yellow is `#dae912`.
- `assets/` holds the product photo, the Stoos photo, the OG image, and the self-hosted Archivo variable font (SIL Open Font License, see `assets/archivo-OFL.txt`).
- `CNAME` points GitHub Pages at uhohbrands.com.

To change copy, edit `index.html` and push to `main`. GitHub Pages redeploys in about a minute.
